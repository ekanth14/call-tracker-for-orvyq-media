# Orvyqmedia Caller App (Android)

Native Flutter Android application for Orvyqmedia employees to place cold calls using their **personal SIM**, with automated device-log verification and mandatory post-call dispositions.

## Key Features

1. **Zero Provider Telephony Fees**: Employees call directly from their personal Android SIM.
2. **On-Device Privacy Compliance (§6)**:
   - Only outgoing calls matching assigned leads are processed.
   - Zero personal calls are ever read, matched, or uploaded.
   - Zero access to contacts, SMS, or audio recordings.
3. **Mandatory Post-Call Dialog (§5)**:
   - Non-dismissible disposition dialog following every call.
   - Reason capture for non-interested leads (backed by database seed reasons).
   - Follow-up scheduling with date/time and channel selection.
4. **Call Lock Protection (§5 & §8)**:
   - Client and server refuse any subsequent call until the pending call dialog is submitted.
5. **10-Second Connected Threshold Rule (§5.1)**:
   - Minimum talk time of $\ge 10$ seconds required to qualify as connected.
   - "Interested" outcome is disallowed on calls with $< 10$s talk time.

## Architecture

Follows the recommended layered Flutter architecture:
- `lib/core/`: Configuration, Material 3 theme, formatters (`PhoneFormatter`, `DateFormatter`).
- `lib/data/`:
  - `models/`: `LeadModel`, `ReasonModel`, `DialAttemptModel`, `UserProfileModel`, `StatsModel`.
  - `services/`: `CallLauncherService`, `PermissionService`, `StorageService`.
  - `repositories/`: `AuthRepository`, `LeadRepository`, `CallingRepository`, `ReasonRepository`.
- `lib/ui/`:
  - `view_models/`: `AuthViewModel`, `QueueViewModel`, `CallingViewModel`, `StatsViewModel`.
  - `views/`:
    - `auth/`: Login and Privacy Consent screens.
    - `queue/`: Assigned leads list with search, filter tabs, stats header, and Call button.
    - `calling/`: Active call state with stopwatch and auto-resume listener.
    - `calling/post_call_dialog_screen.dart`: Mandatory disposition dialog.
    - `health/`: Device health, permissions, and OEM battery optimization guide.

## Building and Distributing the APK

Because Google Play restricts call-log permissions for standard store apps, this app is built as an APK and distributed privately to team members via a secure link (§4.1):

### 1. Prerequisites
- Flutter SDK (3.4+)
- Android SDK (API 34)

### 2. Build Release APK
```bash
cd apps/caller_app
flutter pub get
flutter build apk --release
```
The compiled APK will be located at:
`apps/caller_app/build/app/outputs/flutter-apk/app-release.apk`

### 3. Employee Installation Instructions
1. Download `app-release.apk` on the Android phone.
2. Open the file and allow **Install from Unknown Sources** for that file/browser.
3. Open **Orvyqmedia Caller**.
4. Log in using the credentials generated by the owner in the Web Dashboard.
5. Read and accept the **Privacy Notice**.
6. Grant Phone permission and battery optimization exemption.
7. Start calling!
